Pyaterochka Database

Учебный проект: база данных для сети магазинов «Пятёрочка».

Структура
- categories — категории
- subcategories — подкатегории
- product_groups — группы товаров
- product_types — виды товаров
- brands — бренды
- units — единицы измерения
- products — товары


Как использовать
1. Выполни `schema.sql` в MySQL Workbench.
2. Запусти `inserts.sql` для тестовых данных.
3. Используй `queries.sql` для примеров запросов.
